# Check AMULET params

Checkmate extension for the output of
[`params_atac_amulet()`](https://gregorlueg.github.io/bixverse/reference/params_atac_amulet.md).

## Usage

``` r
checkAtacAmuletParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
