# Check peak calling params

Checkmate extension for the output of
[`params_atac_call_peaks()`](https://gregorlueg.github.io/bixverse/reference/params_atac_call_peaks.md).

## Usage

``` r
checkAtacCallPeaksParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
