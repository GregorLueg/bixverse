# Check LSI params

Checkmate extension for the output of
[`params_atac_lsi()`](https://gregorlueg.github.io/bixverse/reference/params_atac_lsi.md).

## Usage

``` r
checkAtacLsiParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
