# Check rLSI params

Checkmate extension for the output of
[`params_atac_rlsi()`](https://gregorlueg.github.io/bixverse/reference/params_atac_rlsi.md).

## Usage

``` r
checkAtacRlsiParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
