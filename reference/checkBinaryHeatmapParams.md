# Check binary heatmap params

Checkmate extension for the output of
[`params_binary_heatmap()`](https://gregorlueg.github.io/bixverse/reference/params_binary_heatmap.md).

## Usage

``` r
checkBinaryHeatmapParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
