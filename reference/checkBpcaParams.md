# Check BPCA params

Checkmate extension for the output of
[`params_bpca()`](https://gregorlueg.github.io/bixverse/reference/params_bpca.md).

## Usage

``` r
checkBpcaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
