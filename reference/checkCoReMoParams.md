# Check CoReMo params

Checkmate extension for the output of
[`params_coremo()`](https://gregorlueg.github.io/bixverse/reference/params_coremo.md).

## Usage

``` r
checkCoReMoParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
