# Check DGRDL params

Checkmate extension for the output of
[`params_dgrdl()`](https://gregorlueg.github.io/bixverse/reference/params_dgrdl.md).

## Usage

``` r
checkDGRDLParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
