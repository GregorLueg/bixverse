# Check DIALOGUE mixed model parameters

Checkmate extension for checking the stage two DIALOGUE parameters, see
[`params_dialogue_hlm()`](https://gregorlueg.github.io/bixverse/reference/params_dialogue_hlm.md).

## Usage

``` r
checkDialogueHlm(x)
```

## Arguments

- x:

  The list to check/assert

## Value

`TRUE` if the check was successful, otherwise an error message.
