# Check DIALOGUE mixed model params

Checkmate extension for the output of
[`params_dialogue_hlm()`](https://gregorlueg.github.io/bixverse/reference/params_dialogue_hlm.md).

## Usage

``` r
checkDialogueHlmParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
