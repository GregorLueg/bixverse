# Check DIALOGUE decomposition parameters

Checkmate extension for checking the stage one DIALOGUE parameters, see
[`params_dialogue_pmd()`](https://gregorlueg.github.io/bixverse/reference/params_dialogue_pmd.md).

## Usage

``` r
checkDialoguePmd(x)
```

## Arguments

- x:

  The list to check/assert

## Value

`TRUE` if the check was successful, otherwise an error message.
