# Check DIALOGUE decomposition params

Checkmate extension for the output of
[`params_dialogue_pmd()`](https://gregorlueg.github.io/bixverse/reference/params_dialogue_pmd.md).

## Usage

``` r
checkDialoguePmdParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
