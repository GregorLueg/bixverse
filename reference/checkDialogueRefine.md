# Check DIALOGUE refinement parameters

Checkmate extension for checking the stage three DIALOGUE parameters,
see
[`params_dialogue_refine()`](https://gregorlueg.github.io/bixverse/reference/params_dialogue_refine.md).

## Usage

``` r
checkDialogueRefine(x)
```

## Arguments

- x:

  The list to check/assert

## Value

`TRUE` if the check was successful, otherwise an error message.
