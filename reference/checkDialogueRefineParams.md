# Check DIALOGUE refinement params

Checkmate extension for the output of
[`params_dialogue_refine()`](https://gregorlueg.github.io/bixverse/reference/params_dialogue_refine.md).

## Usage

``` r
checkDialogueRefineParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
