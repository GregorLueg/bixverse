# Check GSEA params

Checkmate extension for the output of
[`params_gsea()`](https://gregorlueg.github.io/bixverse/reference/params_gsea.md).

## Usage

``` r
checkGSEAParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
