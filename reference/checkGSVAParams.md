# Check GSVA params

Checkmate extension for the output of
[`params_gsva()`](https://gregorlueg.github.io/bixverse/reference/params_gsva.md).

## Usage

``` r
checkGSVAParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
