# Check ICA n-components params

Checkmate extension for the output of
[`params_ica_ncomp()`](https://gregorlueg.github.io/bixverse/reference/params_ica_ncomp.md).

## Usage

``` r
checkIcaNcompsParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
