# Check ICA params

Checkmate extension for the output of
[`params_ica_general()`](https://gregorlueg.github.io/bixverse/reference/params_ica_general.md).

## Usage

``` r
checkIcaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
