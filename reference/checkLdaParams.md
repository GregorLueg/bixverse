# Check LDA params

Checkmate extension for the output of
[`params_lda()`](https://gregorlueg.github.io/bixverse/reference/params_lda.md).

## Usage

``` r
checkLdaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
