# Check ligand-target params

Checkmate extension for the output of
[`params_ligand_target()`](https://gregorlueg.github.io/bixverse/reference/params_ligand_target.md).

## Usage

``` r
checkLigandTargetParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
