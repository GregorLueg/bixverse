# Check limma-voom params

Checkmate extension for the output of
[`params_limma_voom()`](https://gregorlueg.github.io/bixverse/reference/params_limma_voom.md).

## Usage

``` r
checkLimmaVoomParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
