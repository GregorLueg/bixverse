# Check MELD params

Checkmate extension for the output of
[`params_meld()`](https://gregorlueg.github.io/bixverse/reference/params_meld.md).

## Usage

``` r
checkMeldParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
