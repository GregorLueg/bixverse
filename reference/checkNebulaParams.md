# Check NEBULA params

Checkmate extension for the output of
[`params_nebula()`](https://gregorlueg.github.io/bixverse/reference/params_nebula.md).

## Usage

``` r
checkNebulaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
