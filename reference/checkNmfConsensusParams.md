# Check NMF consensus params

Checkmate extension for the output of
[`params_nmf_consensus()`](https://gregorlueg.github.io/bixverse/reference/params_nmf_consensus.md).

## Usage

``` r
checkNmfConsensusParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
