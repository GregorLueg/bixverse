# Check PPCA params

Checkmate extension for the output of
[`params_ppca()`](https://gregorlueg.github.io/bixverse/reference/params_ppca.md).

## Usage

``` r
checkPpcaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
