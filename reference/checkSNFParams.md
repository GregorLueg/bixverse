# Check SNF params

Checkmate extension for the output of
[`params_snf()`](https://gregorlueg.github.io/bixverse/reference/params_snf.md).

## Usage

``` r
checkSNFParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
