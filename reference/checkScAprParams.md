# Check analytic Pearson params

Checkmate extension for the output of
[`params_sc_apr()`](https://gregorlueg.github.io/bixverse/reference/params_sc_apr.md).

## Usage

``` r
checkScAprParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
