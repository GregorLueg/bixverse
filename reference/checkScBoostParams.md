# Check Boost params

Checkmate extension for the output of
[`params_boost()`](https://gregorlueg.github.io/bixverse/reference/params_boost.md).

## Usage

``` r
checkScBoostParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
