# Check bootstrapped metacell params

Checkmate extension for the output of
[`params_sc_bt_metacells()`](https://gregorlueg.github.io/bixverse/reference/params_sc_bt_metacells.md).

## Usage

``` r
checkScBootstrappedMetacellsParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
