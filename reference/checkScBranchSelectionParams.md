# Check branch selection params

Checkmate extension for the output of
[`params_sc_branch_selection()`](https://gregorlueg.github.io/bixverse/reference/params_sc_branch_selection.md).

## Usage

``` r
checkScBranchSelectionParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
