# Check CellPhoneDB params

Checkmate extension for the output of
[`params_sc_cellphonedb()`](https://gregorlueg.github.io/bixverse/reference/params_sc_cellphonedb.md).

## Usage

``` r
checkScCellPhoneDbParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
