# Check scDblFinder params

Checkmate extension for the output of
[`params_scdblfinder()`](https://gregorlueg.github.io/bixverse/reference/params_scdblfinder.md).

## Usage

``` r
checkScDblFinderParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
