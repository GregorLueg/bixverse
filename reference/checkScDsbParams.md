# Check DSB params

Checkmate extension for the output of
[`params_sc_dsb()`](https://gregorlueg.github.io/bixverse/reference/params_sc_dsb.md).

## Usage

``` r
checkScDsbParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
