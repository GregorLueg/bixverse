# Check Harmony params

Checkmate extension for the output of
[`params_sc_harmony()`](https://gregorlueg.github.io/bixverse/reference/params_sc_harmony.md).

## Usage

``` r
checkScHarmonyParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
