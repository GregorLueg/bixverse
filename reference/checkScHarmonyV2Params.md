# Check Harmony v2 params

Checkmate extension for the output of
[`params_sc_harmony_v2()`](https://gregorlueg.github.io/bixverse/reference/params_sc_harmony_v2.md).

## Usage

``` r
checkScHarmonyV2Params(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
