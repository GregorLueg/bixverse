# Check HVG params

Checkmate extension for the output of
[`params_sc_hvg()`](https://gregorlueg.github.io/bixverse/reference/params_sc_hvg.md).

## Usage

``` r
checkScHvgParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
