# Check MetaCells2 divide and conquer params

Checkmate extension for the output of
[`params_sc_metacells2_dac()`](https://gregorlueg.github.io/bixverse/reference/params_sc_metacells2_dac.md).

## Usage

``` r
checkScMetacells2DacParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
