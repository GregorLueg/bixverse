# Check MetaCells2 params

Checkmate extension for the output of
[`params_sc_metacells2()`](https://gregorlueg.github.io/bixverse/reference/params_sc_metacells2.md).

## Usage

``` r
checkScMetacells2Params(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
