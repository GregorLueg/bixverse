# Check single cell PCA params

Checkmate extension for the output of
[`params_sc_pca()`](https://gregorlueg.github.io/bixverse/reference/params_sc_pca.md).

## Usage

``` r
checkScPcaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
