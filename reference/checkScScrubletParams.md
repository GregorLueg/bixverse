# Check Scrublet params

Checkmate extension for the output of
[`params_scrublet()`](https://gregorlueg.github.io/bixverse/reference/params_scrublet.md).

## Usage

``` r
checkScScrubletParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
