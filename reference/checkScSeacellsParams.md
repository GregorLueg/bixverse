# Check SEACells params

Checkmate extension for the output of
[`params_sc_seacells()`](https://gregorlueg.github.io/bixverse/reference/params_sc_seacells.md).

## Usage

``` r
checkScSeacellsParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
