# Check Seurat CCA params

Checkmate extension for the output of
[`params_sc_seurat_cca()`](https://gregorlueg.github.io/bixverse/reference/params_sc_seurat_cca.md).

## Usage

``` r
checkScSeuratCcaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
