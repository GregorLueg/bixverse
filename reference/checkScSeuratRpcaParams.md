# Check Seurat rPCA params

Checkmate extension for the output of
[`params_sc_seurat_rpca()`](https://gregorlueg.github.io/bixverse/reference/params_sc_seurat_rpca.md).

## Usage

``` r
checkScSeuratRpcaParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
