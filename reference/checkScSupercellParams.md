# Check SuperCell params

Checkmate extension for the output of
[`params_sc_supercell()`](https://gregorlueg.github.io/bixverse/reference/params_sc_supercell.md).

## Usage

``` r
checkScSupercellParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
