# Check synthetic ADT params

Checkmate extension for the output of
[`params_sc_synthetic_data_adt()`](https://gregorlueg.github.io/bixverse/reference/params_sc_synthetic_data_adt.md).

## Usage

``` r
checkScSyntheticDataAdtParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
