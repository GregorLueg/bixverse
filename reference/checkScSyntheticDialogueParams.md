# Check synthetic DIALOGUE params

Checkmate extension for the output of
[`params_sc_synthetic_dialogue()`](https://gregorlueg.github.io/bixverse/reference/params_sc_synthetic_dialogue.md).

## Usage

``` r
checkScSyntheticDialogueParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
