# Check VISION params

Checkmate extension for the output of
[`params_sc_vision()`](https://gregorlueg.github.io/bixverse/reference/params_sc_vision.md).

## Usage

``` r
checkScVisionParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
