# Check WNN params

Checkmate extension for the output of
[`params_sc_wnn()`](https://gregorlueg.github.io/bixverse/reference/params_sc_wnn.md).

## Usage

``` r
checkScWnnParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
