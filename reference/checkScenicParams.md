# Check SCENIC params

Checkmate extension for the output of
[`params_scenic()`](https://gregorlueg.github.io/bixverse/reference/params_scenic.md).

## Usage

``` r
checkScenicParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
