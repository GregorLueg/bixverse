# Check Symphony map params

Checkmate extension for the output of
[`params_symphony_map()`](https://gregorlueg.github.io/bixverse/reference/params_symphony_map.md).

## Usage

``` r
checkSymphonyMapParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
