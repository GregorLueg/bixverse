# Add or replace columns of the ATAC feature table

Add or replace columns of the ATAC feature table

## Usage

``` r
.add_atac_var(x, new_data)
```

## Arguments

- x:

  `SingleCellsAtac` or `SingleCellsMultiModal`.

- new_data:

  data.table with one row per feature, in store order.

## Value

Invisible `NULL`.
