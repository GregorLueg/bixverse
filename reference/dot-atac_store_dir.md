# Directory of the ATAC store of an object

Directory of the ATAC store of an object

## Usage

``` r
.atac_store_dir(x)
```

## Arguments

- x:

  `SingleCellsAtac` or `SingleCellsMultiModal`.

## Value

String. The experiment directory for `SingleCellsAtac`, its `atac`
subdirectory for `SingleCellsMultiModal`.
