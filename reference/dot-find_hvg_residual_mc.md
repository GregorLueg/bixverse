# Residual-based HVG selection for meta cells

Residual-based HVG selection for meta cells

## Usage

``` r
.find_hvg_residual_mc(object, hvg_no, .verbose = TRUE)
```

## Arguments

- object:

  `MetaCells` class.

- hvg_no:

  Integer. Variable features per group.

- .verbose:

  Boolean or Integer. Controls verbosity.

## Value

The object with the HVGs set.
