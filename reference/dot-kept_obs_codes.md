# 0-based codes of an obs column over the kept cells

0-based codes of an obs column over the kept cells

## Usage

``` r
.kept_obs_codes(x, col)
```

## Arguments

- x:

  The single cell object.

- col:

  String. The obs column.

## Value

A list with `codes` (0-based integer, one per kept cell, in kept order)
and `levels`.
