# The marker test, `NULL` resolving to `"lr"` on ATAC and `"wilcox"` otherwise

The marker test, `NULL` resolving to `"lr"` on ATAC and `"wilcox"`
otherwise

## Usage

``` r
.marker_method(store, method)
```

## Arguments

- store:

  List. Output of
  [`.de_store()`](https://gregorlueg.github.io/bixverse/reference/dot-de_store.md).

- method:

  Optional string.

## Value

String.
