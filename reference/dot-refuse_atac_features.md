# Refuse a gene-only method on a peak or tile store

Refuse a gene-only method on a peak or tile store

## Usage

``` r
.refuse_atac_features(object, method)
```

## Arguments

- object:

  The single cell object.

- method:

  String. The method name, for the message.

## Value

Invisible `NULL`, or an error for a peak or tile store.
