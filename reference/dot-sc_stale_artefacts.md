# Labels of every stale artefact on an object

Labels of every stale artefact on an object

## Usage

``` r
.sc_stale_artefacts(x)
```

## Arguments

- x:

  The object owning the cache(s).

## Value

Character vector of `"modality:artefact"` labels, possibly empty. Never
signals: this backs a warning and a `print` method.
