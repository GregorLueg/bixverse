# Record the count mode in both files of an ATAC store

Record the count mode in both files of an ATAC store

## Usage

``` r
.write_count_mode(store_dir, count_mode)
```

## Arguments

- store_dir:

  String. The directory holding the store's two files.

- count_mode:

  String. One of `c("insertion", "paired-insertion", "fragment")`.

## Value

Invisible `NULL`.
