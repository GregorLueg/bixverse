# Default parameters for the SCENIC GradientBoosting (GRNBoost2) regression learner

Default parameters for the SCENIC GradientBoosting (GRNBoost2)
regression learner

## Usage

``` r
params_scenic_gradient_boosting_defaults()
```

## Value

A named list with the following elements:

- n_trees_max - Any. TODO Defaults to `1000L`.

- learning_rate - Any. TODO Defaults to `0.01`.

- max_depth - Any. TODO Defaults to `3L`.

- min_samples_leaf - Any. TODO Defaults to `50L`.

- early_stop_window - Any. TODO Defaults to `25L`.

- subsample_rate - Any. TODO Defaults to `0.9`.

- n_features_split - Any. TODO Defaults to `0L`.
