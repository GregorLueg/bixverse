# Default parameters for the SCENIC RandomForest regression learner

Default parameters for the SCENIC RandomForest regression learner

## Usage

``` r
params_scenic_random_forest_defaults()
```

## Value

A named list with the following elements:

- n_trees - Any. TODO Defaults to `250L`.

- min_samples_leaf - Any. TODO Defaults to `50L`.

- n_features_split - Any. TODO Defaults to `0L`.

- subsample_rate - Any. TODO Defaults to `0.632`.

- bootstrap - Any. TODO Defaults to `FALSE`.

- max_depth - Any. TODO Defaults to `8L`.

- subsample_frac - Any. TODO Defaults to `NULL`.
