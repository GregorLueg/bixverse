# Fixed-width tiles over chromosomes

**\[experimental\]**

## Usage

``` r
rs_atac_genome_tiles(chroms, sizes, width)
```

## Arguments

- chroms:

  Character vector. Chromosome names.

- sizes:

  Integer vector. Their lengths.

- width:

  Integer. The tile width.

## Value

A list with `chrom`, `start` and `end`.
